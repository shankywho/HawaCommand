# Project Demonstration & Source Videos

This directory contains the video assets and the final compiled 160-second video presentation for HawaCommand.

## Files

1. **`HawaCommand_Final_160s_Presentation.mp4`** (69.4 MB)
   - Final 160-second demonstration video (1920x1080 @ 30fps).
   - Starts with the Web Portal console frame.
   - Includes AWS Infrastructure proof (EC2, Kinesis, DynamoDB, S3).
   - Includes muted Hardware IoT demonstration with on-screen device labels.
   - Includes Flutter Citizen mobile application showcase.
   - Clean audio track without voiceover, ready for voice narration.

2. **`web_portal.mp4`** (12 MB)
   - Source recording of the HawaCommand Web Command Console and Landing Portal.

3. **`aws_dashboard.mp4`** (14.5 MB)
   - Source recording of the AWS Cloud Console in `ap-south-1` Mumbai (EC2, Kinesis, DynamoDB, S3).

4. **`hardware_iot_device_video.mp4`** (7.1 MB)
   - Source recording of the physical IoT edge prototype (MQ-135 sensor, ESP-32 board, buzzer, stepper motor).

5. **`citisen_mobile_app.mp4`** (7.9 MB)
   - Source recording of the Flutter Hawa Citizen mobile application.
